# Phase 1A — Engine: Generation, Minor Fixes, Speed Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the existing generation paths linear-time, fix the review's minor defects, expose sampling and stop controls on the CLI, and speed up the kernels with external crates where measurements justify them.

**Architecture:** Generation fixes stay in `ferrum_core/src/slm.rs`. Param counting is a new default method on the `Layer` trait. Speed work swaps the hand-written pool in `parallel.rs` for `rayon` and benchmarks safe-API matmul crates (`ndarray`, which uses `matrixmultiply` internally, and `faer`) behind `ops::matmul` / `ops::linear_forward`. The kernel with the best measured result is kept.

**Tech Stack:** Rust 2021; `rayon 1.12`, `ndarray 0.17`, `faer 0.24` (candidates; only winners stay in `Cargo.toml`).

**Spec:** `docs/superpowers/specs/2026-10-09-dataops-serve-eval-design.md` (§4.4–§4.6). Phase 0 plan: `docs/superpowers/plans/2026-10-09-p0-shared-surfaces.md`.

## Global Constraints

- Start from the Phase 0 tip of `feat/dataops-serve-eval`, in a worktree (`git worktree add ../Ferrum-A -b feat/dos-A feat/dataops-serve-eval`).
- `#![forbid(unsafe_code)]` stays in `ferrum_core`. `matrixmultiply::sgemm` and the `gemm` crate are `unsafe fn` and must not be called directly.
- Results bit-for-bit identical at `FERRUM_NUM_THREADS=1` vs N. Any crate that breaks this is rejected.
- `ferrum_core` builds for `wasm32-unknown-unknown`. Thread crates are `[target.'cfg(not(target_arch = "wasm32"))'.dependencies]` only.
- All files are GGUF; Ferrum models are GPT-2-compatible GGUF that must keep running in llama.cpp (Phase 0-G's compat test must stay green).
- Every feature lands with its unit tests in the same commit (test first). No `unsafe` code.
- Each commit: `cargo test --workspace --release`, `cargo fmt --all -- --check`, `cargo clippy --workspace --all-targets -- -D warnings`, and `(cd ferrum_gui && cargo check --all-targets)` when public `ferrum_core` APIs change.
- Do not edit `ReadMe.md`, `Manual.md`, `Status.md` (Phase 2 owns docs). Record measured numbers in commit messages.
- New `main.rs` flags are added to the `const *_FLAGS` tables from Phase 0 Task 5.

## Note

- `--tie` file size is handled by Phase 0-G: a tied model omits `output.weight`. This plan only fixes the reported parameter count.
- Reference 500K config (all dims multiples of 32 for Q8_0): `--context 128 --embed 96 --heads 4 --blocks 3 --hidden 320 --vocab 1024` = **507,552** params (no LM-head bias after Phase 0-G).

## Review Focus

1. Generating 10× the context window — linear cost, no per-token re-prime. → Task 1 test `bpe_generation_reprimes_once_per_half_window`.
2. A seed containing `<|endoftext|>` on an EOS model — the returned text must still start with the seed verbatim. → Task 1 test `seed_with_doc_separator_is_preserved`.
3. `--stop` given several times and a stop string that spans two tokens. → Task 2 test `cli_generate_stop_list_cuts_output`.
4. Resuming a budgeted run mid-epoch — epoch boundaries line up with an uninterrupted run. → Task 4 test `resume_mid_epoch_finishes_the_partial_epoch`.
5. A thread-count change after the kernel swap — same model bytes and same generated text. → Task 5 test `cli_outputs_identical_across_thread_counts`.

```rust
        if let Some(mut cached) = CachedTransformer::try_new(&self.model) {
            let cap = cached.capacity().max(2);
            let seed_ids = tok.encode_docs(seed);
            let mut window: Vec<usize> = if seed_ids.is_empty() {
                vec![self.bos_id()]
            } else {
                seed_ids[seed_ids.len().saturating_sub(cap)..].to_vec()
            };
            let mut dist = cached.prime(&window)?;
            let mut cont = String::new();
            let mut cont_chars = 0usize;
            let mut emitted = 0usize; // continuation chars streamed so far
            let mut pending: Vec<u8> = Vec::new();
            let mut steps = 0;
            let stop_len = stop.map_or(0, str::len);
            while cont_chars < num_chars && steps < max_steps {
                let logits: Vec<f32> = dist.iter().map(|&p| p.max(1e-12).ln()).collect();
                let next = sample_with_params(&logits, params, &window, rng);
                steps += 1;
                let before = cont.len();
                pending.extend_from_slice(tok.token_bytes(next).unwrap_or(&[]));
                drain_utf8(&mut pending, &mut cont);
                cont_chars += cont[before..].chars().count();
                if let Some(s) = stop {
                    let from = before.saturating_sub(stop_len);
                    let from = (0..=from).rev().find(|&i| cont.is_char_boundary(i)).unwrap_or(0);
                    if let Some(i) = cont[from..].find(s) {
                        budget = cont[..from + i + s.len()].chars().count().min(num_chars);
                        break;
                    }
                }
                let avail = cont_chars.min(budget);
                if avail > emitted {
                    let delta: String = cont.chars().skip(emitted).take(avail - emitted).collect();
                    on_text(&delta);
                    emitted = avail;
                }
                window.push(next);
                if window.len() > cap {
                    window.drain(..window.len() - cap / 2);
                    dist = cached.prime(&window)?;
                } else {
                    dist = cached.feed(next)?;
                }
            }
            if !pending.is_empty() {
                cont.push_str(&String::from_utf8_lossy(&pending));
            }
            let tail: String = cont.chars().skip(emitted).take(budget.saturating_sub(emitted)).collect();
            if !tail.is_empty() {
                on_text(&tail);
            }
            let out: String = seed.chars().chain(cont.chars().take(budget)).collect();
            return Ok(out);
        }
```

Delete the now-unused `flush`/`stop_cut` closures if only the fallback branch used them. If the fallback branch still uses them, keep them for that branch. Move `let mut ids = tok.encode(seed);` into the fallback branch. #[cfg(not(target_arch = "wasm32"))]
```rust
fn pool() -> &'static rayon::ThreadPool {
    static POOL: OnceLock<rayon::ThreadPool> = OnceLock::new();
    POOL.get_or_init(|| {
        rayon::ThreadPoolBuilder::new()
            .num_threads(num_threads())
            .thread_name(|i| format!("ferrum-worker-{i}"))
            .build()
            .expect("ferrum: cannot start worker threads")
    })
}

pub fn run<K>(m: usize, n: usize, kernel: K) -> Vec<f32>
where
    K: Fn(usize, usize, &mut [f32]) + Send + Sync + 'static,
{
    let mut out = vec![0.0f32; m * n];
    #[cfg(target_arch = "wasm32")]
    kernel(0, m, &mut out);
    #[cfg(not(target_arch = "wasm32"))]
    {
        use rayon::prelude::*;
        let threads = num_threads().max(1).min(m.max(1));
        let rows_per = m.div_ceil(threads).max(1);
        if threads <= 1 || n == 0 {
            kernel(0, m, &mut out);
        } else {
            pool().install(|| {
                out.par_chunks_mut(rows_per * n).enumerate().for_each(|(b, block)| {
                    let r0 = b * rows_per;
                    kernel(r0, r0 + block.len() / n, block);
                });
            });
        }
    }
    out
}
```

The row split (and thus bit-identical results at any thread count) is unchanged. Delete the old `Job`/`pool`/`senders` code.
